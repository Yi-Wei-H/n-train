# 部署本服务说明

## 部署中间件和数据库

前置：已安装好 docker
1. 将 docker-compose.yml 、service.env 和 broker.conf 上传至服务器
> 因为 docker-compose.yml#114 原因，broker.conf 需要放置在 ./rocketmq 目录下
> broker.conf 中 brokerIP1 需要更改为自己的私网IP，若服务启动在
2. 执行命令(假设两个文件在同一级位置)
```bash
# 第一次或全启动
docker compose -f docker-compose.yml --env-file service.env up -d
# 启动单个服务(重启也可以，可以让新配置生效)
docker compose -f docker-compose.yml --env-file .env.prod up -d [服务名]
# 查看状态
docker compose -f docker-compose.yml --env-file .env.prod ps / docker ps
# 重启全部服务
docker compose -f docker-compose.yml --env-file .env.prod restart
# 停止全部服务
docker compose -f docker-compose.yml --env-file .env.prod stop
# 停止并删除卷
docker compose -f docker-compose.yml --env-file .env.prod down
```
3. 查询日志
```bash
# 实时看单个服务日志
docker compose -f docker-compose.yml --env-file .env.prod logs -f [服务名]
# 看最近200行日志
docker compose -f docker-compose.yml --env-file .env.prod logs --tail=200 -f [服务名]
```
4. 远程连接执行 sql 下的各个 sql 脚本
5. 开放端口(可选)：若部署在服务器上且与后台服务分开需要开放端口：3306、5432、6379、9876、10911、8848、9848

## 部署后台服务

前置： 已安装好 JDK21
1. 在 nacos 上配置好 deploy/nacos/configs 文件夹中的配置，使用 public 命名空间
2. 打包全部服务并修改 jar 包名(参考 env.sh)，将 deploy/bin 的脚本和 jar 包全部上传到服务其中
3. 根据之前上传的 service.env 位置更改 env.sh#14，确保启动服务时能够读到
4. 在服务器的 /etc/host.conf 追加 127.0.0.1 remotelist (当你把数据库和中间件部署在同一个服务器时)，若部署在其他地方更换 公网IP
5. 根据实际情况修改 env.sh#27~48 的 JVM 参数，确保正常运行
6. 根据实际情况开放端口，若你的后台服务与前端分开部署

> 在项目中使用的 IP 统一由 remotelist 控制

## 部署前端

1. 安装 nginx
```shell
dnf install -y nginx
systemctl enable --now nginx
```
2. 构建前端，并上传 dish 文件夹下的文件，复制到你想放的位置
> 构建前先在 `train-ui/web` 与 `train-ui/admin` 各自创建 `.env`（参考同目录 `.env.example`），
> 填 `VITE_AES_KEY`（16 字符，必须与后端 `NTRAIN_AES_KEY` 一致）；缺失会直接构建/启动报错
3. 上传 deploy/nginx/nginx.conf，将其放置 /etc/nginx/conf.d/*.conf (没有就创建)
4. 检查语法并重启
```shell
nginx -t
systemctl reload nginx
```
5. 放开端口：9000、9001
